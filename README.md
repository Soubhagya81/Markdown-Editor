# Markdown Editor with Live Preview

## Description
A real-time Markdown editor using Node.js and React. This editor should
convert Markdown text to HTML in real-time and display the rendered HTML in a live
preview pane.

## Installation
Instructions on how to install and set up the project.

```bash
# Clone the repository
git clone https://github.com/Soubhagya81/Markdown-Editor.git

# Install dependencies
npm install

Instructions on how to use the project.
# Run the project
npm run dev
